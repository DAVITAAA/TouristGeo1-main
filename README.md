# TouristGeo

A modern tourism and location-based web application designed to help users explore destinations, discover points of interest, and access geographic information through an intuitive and interactive interface.


## Overview

TouristGeo provides users with an interactive way to explore geographic locations, tourist attractions, and destination information. The application combines mapping functionality with a clean user experience to make travel planning and location discovery more accessible.

* Interactive map visualization
* Location and destination exploration

## Getting Started

### Prerequisites

Before running the project, ensure you have:

* Node.js (v18 or later recommended)
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/DAVITAAA/TouristGeo1-main.git
cd TouristGeo1-main
```

Install dependencies:

```bash
npm install
```

Configure environment variables:

```bash
cp .env.example .env.local
```

Add the required environment variables to `.env.local`.

### Running the Application

Start the development environment:

```bash
npm run dev:all
```

The application will be available locally after startup.
